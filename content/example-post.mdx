published post looks like on the site.

## How this works

Every `.mdx` file in the `content/` folder becomes a post automatically. The
frontmatter block at the top (between the `---` lines) sets the title,
publish date, summary, and tags — the tags also drive the knowledge graph,
which auto-links posts that share a tag.

Delete this file once you've added your own posts, or edit it in place to
get started.
